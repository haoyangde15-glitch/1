# THE VEIL — 禁区档案局

黑红科技感灵异事件网站原型，包含任务档案、演示聊天大厅、免登录证据影像播放器和可选 WebSocket 公共聊天服务。

## 本次视频修复
- 新增 `assets/case_013_compat.mp4`：兼容版 H.264/AAC MP4，使用 fast-start 元数据布局。
- 播放器不再依赖自动播放；点击明确的「播放档案影像 / PLAY」按钮开始播放。
- 增加播放状态、错误提示与单独打开视频的备用入口。
- 原始视频保留为备用源。

## 推荐运行方式

**Windows：** 双击 `start.bat`，然后浏览器打开 `http://localhost:4173`。

**macOS / Linux：** 在本目录运行 `./start.sh`，然后打开 `http://localhost:4173`。

**通用方式：** 安装 Node.js 后，在本目录执行：

```bash
node server.js
```

推荐通过本地服务器或部署后的 HTTP/HTTPS 地址打开，而不是直接使用 `file://` 打开 HTML；部分移动浏览器会限制本地文件媒体访问。

## 聊天说明
- 不需要登录。
- 同一服务端上的在线访客可通过 WebSocket 公共频道实时聊天。
- 消息仅在内存中广播，不持久化；演示模式不会伪装成真实在线用户。
- 公开部署时请使用 HTTPS/WSS，并按需增加内容审核与滥用防护。

## 备注
网站是虚构恐怖氛围体验，不是现实紧急服务。无需外部 AI 模型或 API 密钥。
